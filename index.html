01 / PROBLEM

全留太贵，全删太狠。

素材只会越拍越多：一小时 4K 可能上百 GB。全留着，存储成本一直涨；全删了，又怕以后还要用。真正卡住的往往不是「剪得慢」，而是素材从来没有按价值分流。

P.01 / 两难

留着占地方，
删了怕后悔

一条拍完的片子里，真正要留的可能只有几分钟：一段留作母版，一段只发平台，一段只要声音，其余都是废片。它们本来就在同一段素材里，删除时只能整条赌运气。

P.02 / 断点

选、剪、分、导，
散落在四个地方

传统软件也能剪辑和导出，但选片段、标入点出点、逐段设置导出参数各在一处，无法在一条时间线上一次完成，多个片段就得重复多轮。

P.03 / 代价

时间花在重复操作，
空间留给废片

逐段导出、单独抽音频、再用表格记下哪些能删；手写 ffmpeg 还要为每一段拼参数。真正有用的素材，并没有因此变得更好找。

VShunt 把这一整套压缩成一次操作：在一条时间线上边看边选、边切边分流，每个片段落下时就已确定去向与规格，最后一次性导出。原片即可放心删除，只为好片留空间，不为废片留位置。

02 / WORKFLOW

四步，从素材到交付。

不来回切时间线，不反复调整导出。只需一遍即可完成选片、剪辑、转码设定和导出规整。

STEP 01

识别

对话类素材仅凭画面难以判断价值。先识别字幕，通过文字快速了解每段内容，按关键词搜索并直接跳转。

STEP 02

切分

不用单独设入点和出点：X 键即可自动分段。配合字幕和波形，切口能精确落在一句话的停顿上。

STEP 03

分流

点击片段或使用快捷键，为每段指定去向：源片复制、预设压缩、自定义规格、仅提取音频，或直接废弃忽略。

STEP 04

导出

按照既定参数即可一次性全部导出，也支持单独导出每一段，不用每个片段挨个操作。

HIGHLIGHT / ONE PASS

05 / NATIVE · NOT A WEB VIEW

不是套壳。
是原生播放器。

播放、seek、波形和快捷键直接跑在 AVFoundation 与 AppKit 上，不经过浏览器内核。拖动、逐帧、缩放都是原生级的手感，标准只有一个：像 QuickTime Player 一样跟手。

ELECTRON / WEBVIEW / 网页套壳

  • 解码和渲染受浏览器限制，部分格式放不了，4K 高码率素材吃力
  • 拖动和逐帧有延迟，画面跟不上手
  • 自带一整个浏览器内核，内存占用高

VSHUNT 原生

  • 系统硬件解码，4K、HEVC、高码率素材也能流畅播放
  • 拖到哪画面跟到哪，逐帧即按即到
  • 少一层浏览器内核，更轻量

11 / FAQ

几个常见问题。

和 Electron / WebView 套壳工具有什么区别？

VShunt 的播放、seek、波形和快捷键直接调用 AVFoundation / AppKit，不经过浏览器内核。用起来的区别是：拖动时间线画面随手走，逐帧和滚轮微调即按即到、不回弹。早期的 WebView 版本在这些地方达不到要求，所以改用 Swift 原生重写。

会有 Windows 版吗？

会，但不会简单移植。Windows 版需要重做播放器、波形、帧级 seek 与快捷键，具体时间与系统要求确定后会在本页公布。

会帮我删掉原片吗？

不会。VShunt 只做标记和导出，删除权始终在你手里。你可以先按分流结果把需要的片段全部导出，确认无误后再自己清理原片。

必须配置 API Key 才能用吗？

不必须。切分、片段管理、时间线、波形、导出以及 Apple Speech 本地字幕识别都可以直接使用。只有豆包云端识别与 OSS / TOS 存储需要自行配置凭证。

我的视频会被上传吗？

本地识别路径不会上传音频。选择豆包云端识别时，音频会上传到你自己配置的对象存储，识别结束自动删除远端音频对象；视频文件本身不会被上传。

支持哪些输入和输出格式？

输入推荐 mp4 / mov，常见格式基本都能打开。不需要压缩的片段直接复制原片；需要压缩时按源视频的编码重新编码（H.264 素材输出 H.264，HEVC 素材输出 HEVC），容器可选 MP4 或 MOV，分辨率、帧率、码率都能自定义，也内置了原分辨率高画质 / 小体积、4K、1080p、720p、480p 六档场景预设，按源分辨率限制不放大；4K 交付在硬件可用时自动走硬编，否则回退软编。纯音频直接复制原音轨，格式跟随源文件，常见为 AAC。

为什么要求 macOS 26.0？

本地字幕识别依赖系统的 SpeechAnalyzer 语音框架，它从 macOS 26.0 才开始提供，因此最低系统版本为 macOS 26.0。

如何卸载？

把 Applications 中的 VShunt 移到废纸篓即可。工程数据、模板与配置保存在 ~/Library/Application Support/VShunt，如需彻底清理可一并删除。
